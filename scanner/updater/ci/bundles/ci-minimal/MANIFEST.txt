Usage
-----
This bundle is embedded in the scanner Docker image at:
  /etc/scanner/ci-minimal-bundle.zip

Configure scanner to use it:
  vulnerabilities_url: file:///etc/scanner/ci-minimal-bundle.zip

Regeneration
------------
To regenerate this bundle:
  1. ./scanner/updater/ci/extract-test-cves.sh
  2. ./scanner/updater/ci/download-public-bundle.sh
  3. ./scanner/updater/ci/generate-uncompressed-for-review.sh
  4. ./scanner/updater/ci/add-synthetic-cves.sh
  5. ./scanner/updater/ci/trim-bundle-fields.sh
  6. Compress and package (see trim-bundle-fields.sh)
  7. ./scanner/updater/ci/validate-bundle-coverage.sh

Or use the orchestrator:
  ./scanner/updater/ci/generate-ci-bundle.sh (needs update to include trim step)
